# Model Y 白版与方向依据

## 权威顺序

白版几何 > 用户当前要求 > 已观察到的 Sample 排布惯例。样例不是几何标准，也不是新主题的风格参考。部分样例在中心留空处画了车顶或铺了白色背景，这些内容不能进入本白版的透明洞。

内置模板与用户提供的原图逐字节相同，SHA-256：
`145e56ff1d9d3d5d3c3bac4ce1b331387858cb3ee7f17dce7d1de2100bf42a4b`。

模板为 RGBA；大量留空是 `(0,0,0,0)`，外围也有 `(255,255,255,0)`。不能仅按 RGB 白色提取分区，更不能把图像查看器显示的黑底视为车漆。以 alpha 和亮度共同识别白色岛，并保留原有细黑边与抗锯齿。

## 样例证据与限制

- `Model_Y_Pre-20_103310.png` 的侧门文字、山形条带，以及 `Model_Y_Pre-20_104526.png` 的人物，支持左侧图案顶端朝 +x、右侧朝 -x 的惯例；上下门板沿同一方向排列。
- `Model_Y_Pre-20_103328.png`、`Model_Y_Pre-20_130513.png` 的中央上方主体为倒向；`Model_Y_Pre-20_104526.png` 的主体为正向。不能把任一作者的引擎盖方向当作实车事实。
- `Model_Y_Pre-20_104434.png`、`Model_Y_Pre-20_130552.png` 等在中心洞中绘有图案；本技能不得照搬这个差异。
- 源 Sample 分辨率有 629、740、1024、1088，不应据此调整白版尺寸。参考关系已记录在本文，安装包无需依赖源 Sample。
- 所有部位实际贴合、横幅方向与跨缝连续性都尚未实车验证。技能能检查文件与几何偏差，不能保证 AI 每次精确保持 UV，也不能用“脚本通过”替代实车确认。

## 提示词要点

说明：这是固定 UV 平面展开图，不是 3D 汽车图；只更改白色岛内的图案；岛的位置、轮廓、细条、透明间隙、中心空洞必须保持；不重排岛、不画车顶、不加文字标签；主题、配色跨部位统一；主体远离接缝；左右侧图案方向分别指定；无额外标语、水印或背景。

不要让模型把白版作为画面中的一张纸、展示面板或参考缩略图。它本身就是需要着色的编辑目标。

## 已观察到的生图限制

2026-11-03 的橘猫主题实际测试中，首图和一次定向修正都返回 1254×1254，而不是要求的 1024×1024；两张分别为 1,607,264 和 1,449,204 字节。门板主体仍正立于画布，未执行要求的侧向旋转；透明区可见杂点和轮廓偏差。两张均为未通过检查的候选图。

这不是所有后续生成都会失败的结论，但证明了“提示词中指定”不等于“实际满足”。尺寸、透明范围、体积必须读取文件检查，侧向排布必须查看图片；不要宣称纯生图已经稳定产出可用车机贴图。按技能的一次修正上限处理，不能无限重试，也不能在报告中隐去失败。
